# Contributing to OpenDefendable

OpenDefendable accepts contributions that improve truth, protocol clarity, audit reproducibility, and public claim hygiene.

## What to contribute

- protocol clarifications
- audit index updates
- scoreboard updates after accepted audits
- repo utility summaries
- limitation statements
- claim-hygiene corrections tied to evidence

## What not to claim

Do not claim:

- production readiness
- certification
- insurance coverage
- external SaaS enforcement
- immutable proof
- blockchain anchoring
- owner approval

unless a later accepted audit explicitly clears that claim.

## Contribution workflow

1. Link the claim or surface you are changing.
2. Link the audit tape or code evidence that justifies the change.
3. State whether the change affects:
   - protocol
   - scoreboard
   - audit index
   - utility status
   - limitations
4. Keep language concrete and verifiable.

## Verification standard

- builder output is not enough
- public release copy must resolve back to code, docs, or audit tape
- scoreboard changes should follow accepted owner-approved audits
