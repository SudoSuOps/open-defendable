# Claim Hygiene Protocol

Purpose: stop public surfaces from outrunning code, deployment, or audit evidence.

Inputs:
- public message
- source code
- deployed behavior
- accepted audit tape

Outputs:
- aligned claim
- roadmap label
- limitation label
- repair queue entry

Pass/fail rules:
- no production-ready wording without clearance
- no external enforcement claim without proof
- no router-in-path claim without verified integration

Status label:
- `READY_WITH_LIMITATIONS`

Limitations:
- relies on current accepted audit state

Related:
- main-site audit
- deployed-utility audit
